# Wine Recommendation System using NLP

## Problem Statement
Selecting the right product from a large catalog can be challenging for customers. This project builds a recommendation system that suggests similar wines based on user queries using natural language processing techniques.

---

## Objectives
- Process and analyze textual wine descriptions  
- Generate semantic embeddings for similarity comparison  
- Build a recommendation system based on user input  
- Improve recommendation accuracy beyond keyword matching  

---

## Dataset
- Wine Reviews Dataset (130,000+ records)  
- Features: Wine description, variety, price, rating  

---

## Tools and Technologies Used
- Python  
- Sentence Transformers  
- NMSLIB  
- Pandas, NumPy  
- Matplotlib  

---

## Approach
- Cleaned and processed textual data  
- Generated embeddings using Sentence Transformers  
- Implemented similarity search using NMSLIB  
- Built a query-based recommendation system  

---

## Key Insights
- Semantic embeddings capture deeper meaning than keyword matching  
- Similar wines can be identified based on description context  
- NLP improves recommendation quality significantly  

---

## Business Impact
- Enhances user experience in e-commerce platforms  
- Helps customers discover relevant products quickly  
- Increases customer engagement and sales
